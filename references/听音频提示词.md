# 听音频提示词与数据格式

所有"听"的环节都只给模型音频（`chunks/*.mp3`、`clips/*.mp3`），不给视频、不给画面。

**模型不报时间戳。** 有字的内容一律用 readable.txt 里的 S 编号和 ASR 原字定位，时间由脚本算。只有 ASR 没出字的地方（`[未识别]`、被 ASR 合并掉的卡壳）才写时间，用**整条秒数**（保留两位小数）。

模型能自己写文件就直接写；不能就把 JSON 原样输出，由 agent 存到对应路径。允许 JSON 外面包一层 ```json 代码块。

---

## 一、拿着 ASR 稿听原片、定删除（第 3 步）

**输入：** `1_音频/chunks/chunk_NNN.mp3`；`2_听写/readable.txt` 里 `## chunk_NNN` 那一节；`references/剪辑规则.md`；可选口播稿、专名表。

**提示词：**

```text
你在听一段口播录音（chunk_NNN，时长 X 秒，块内 0 秒 = 整条 A 秒）。下面是 ASR 对这一段的识别稿：每行一个句子编号、整条时间、ASR 文字；[静] 是停顿，[未识别] 是有声音但 ASR 没出字的地方。

ASR 的时间是准的，字和判断不可信。你的任务是边听边决定删什么，不用报时间：
1. 重说、残句、说一半换气重来：按剪辑规则删前保后。听语气判断哪一遍是完整说完的，不要只看文字像不像。
2. 句内卡壳、重复的几个字（如“它给的每它给的每个字”、“Cla Claude”）：指出句子编号和要删的那几个字，照抄 ASR 稿里的写法。
3. ASR 把卡壳合并掉、稿里没有的（你听到了“Cla”但稿里只有一个“Claude”）：写出大概整条时间（A + 块内秒数），标出来要放大复听。
4. 每个 [未识别]：是呼吸/杂音就不用写；是人说的话就写出来，说明删还是留。
5. 叹气、笑、有意的停顿：按剪辑规则判断留不留。
6. 不是口误但内容冗余的（前句结尾和后句开头说同一件事、跑题的自述）：单独列为“可删建议”，不要标删除。

ASR 稿：
<粘贴 readable.txt 里 ## chunk_NNN 一节>

只输出 JSON：
{"chunk":"chunk_NNN.mp3",
 "items":[{"id":"A01","type":"句间重复","sids":"S012-S013","text":"","keep":"S014","reason":"","risk":"low","delete":true},
          {"id":"B01","type":"句内重复","chars":{"sid":"S020","del":"它给的每","nth":1},"reason":"","risk":"high","delete":true},
          {"id":"D01","type":"卡顿词","start":512.30,"end":512.62,"text":"Cla","reason":"ASR 合并进了 Claude","risk":"high","delete":true}],
 "missed_speech":[{"near":"S031","approx":233.4,"text":"","note":""}],
 "suggest":[{"sids":"S044-S046","why":""}]}
```

agent 把各块 `items` 合并进 `3_分析/candidates.json`（id 全局唯一），`suggest` 整理进 `3_分析/可删建议.md`，`missed_speech` 记进 `口误分析.md`。

### candidates.json 格式

```json
{"items": [
  {"id": "A01", "type": "句间重复", "sids": "S012-S013", "keep": "S014", "reason": "S012、S013 是 S014 没说完的前两遍", "risk": "low", "delete": true},
  {"id": "B01", "type": "句内重复", "chars": {"sid": "S020", "del": "它给的每", "nth": 1}, "reason": "删前保后", "risk": "high", "delete": true},
  {"id": "D01", "type": "卡顿词", "start": 512.30, "end": 512.62, "text": "Cla", "reason": "ASR 没单独出字", "risk": "high", "delete": true}
]}
```

| 字段 | 说明 |
|---|---|
| id | 唯一。建议前缀：A 句间重复、B 句内重复、C 残句、D 卡顿词、F 语气词、R 稿对齐、S 接缝。不要用 G/H/T/U/P 开头，留给脚本 |
| type | 句间重复 / 句内重复 / 残句 / 重说纠正 / 卡顿词 / 语气词 / 连续语气词 / 稿里没有 / 接缝杂音 |
| sids | 整句删除。`"S012"`、`"S012-S015"` 或 `["S012","S014"]` |
| chars | 句内删除。`{"sid","del","nth"}`，可以是列表。`del` 照抄 ASR 原字，忽略标点；同一句里出现多次用 `nth` 指第几次 |
| start / end | 只给 ASR 没出字的内容用，整条秒数。脚本吸附到静音/能量谷并要求复听 |
| keep | 保留的版本（S 编号或原话），给人看 |
| risk | low / high，按剪辑规则第 2 节判 |
| delete | 剪不剪。单个语气词 false；高风险项复听后仍拿不准 false |

静音、开头、结尾、接缝里的呼吸杂音不用写，脚本自动处理。

### 放大复听（高风险项）

先 `clip` 切片（脚本会打印片段起点 X）。

```text
这是从整条录音 X 秒处截出的 Y 秒片段。对应 ASR 稿：
<粘贴相关几行>
我打算删掉“<被删原话>”，保留“<保留版本>”。请回答：
1. 保留的版本是否完整覆盖了被删内容的意思？被删内容里有没有保留版本没有的信息？
2. 被删和保留的两遍，哪遍语气更完整、更自然？
3. 删掉后前后接起来会不会吞字或不通？
（只有 ASR 没出字的内容才需要回答：它在片段里从第几秒到第几秒，两位小数）
只输出 JSON：{"covered":true,"unique_info":"","better":"keep|deleted","risk_note":"","start":null,"end":null}
```

`covered` 为 false 或 `unique_info` 不为空 → 不删，或改成只删重复的那几个字。`better` 是 deleted → 换成删另一遍。

## 二、剪后音频接缝验收（第 4 步）

**输入：** `4_剪辑/vN/听音包/chunks/chunk_NNN.mp3`、`4_剪辑/vN/splices.txt`（按听音块分组，每个接缝给块内时间和整条时间，跨 take 的带 ⚠️）、`保留稿.txt`。

一块只听一次：接缝和残留口误在同一遍里判完。听完仍拿不准的接缝攒齐了再一次放大复听。

**提示词：**

```text
这是剪辑后的口播音频（chunk_NNN，本块从剪后整条 X 秒开始）。下面列出本块全部剪辑接缝（块内秒数）。这一遍里把所有接缝都判完，逐个听每个接缝前后 2 秒：
- 吞字：接缝处有字被切掉一半或整个丢了
- 爆音/咔哒声
- 残留口误：本该删掉的重复、半句、卡壳还在
- 语义断裂：前后接不上，像少了一句
- 节奏：停顿太短像抢话，或者还是太长
- 标了“跨 take”的：前后语气、音量、劲头接不接得上（前一句已经降调收尾、后一句突然换了状态，都算接不上）
另外整块听一遍，列出还残留的口误（给块内时间和原话）。

接缝：
<粘贴本块的接缝>

只输出 JSON：
{"chunk":"chunk_NNN.mp3","splices":[{"n":1,"t":0.00,"ok":true,"issue":"","fix":""}],"residual":[{"start":0.00,"end":0.00,"text":"","why":""}]}
```

agent 汇总写 `4_剪辑/vN/验收.md`：通过几个、问题几个、每个问题怎么改（换保留哪一遍 / 加删 / 取消删 / `--protect`）。有 `ok: false` 或 `residual` 就不能 `--accepted`；跨 take 接不上又找不到替换版本的，记进验收.md 并在汇报里列出，可以继续往下走。

## 三、字幕校字（第 6 步）

**输入：** `4_剪辑/vN/听音包/chunks/chunk_NNN.mp3`、`5_字幕/vN/lines.txt` 里落在本块时间范围内的行、口播稿、专名表。

**提示词：**

```text
这是剪辑后的口播音频（chunk_NNN，块内 0 秒 = 剪后整条 X 秒）。下面是 ASR 生成的字幕草稿，每行：行号 | 剪后整条时间 | 文字。时间已经定死，不要改。
边听边校对文字，只列出要改的行：
1. 同音错字、专名写错（专名表：<专名表>；比如 剪音→剪映，claud→Claude）。
2. 汉字数字改阿拉伯数字（“八分钟”→“8分钟”，“四分二十一秒”→“4分21秒”）。
3. 只写音频里真实说出的话，不添加、不总结、不改意思；语气词不上字幕。
4. 一个词被断在两行（“根据文|字和时间轴”）：把 1–3 个字挪到相邻行，两行都写出来。
5. 每行不超过 16 个字；不加标点。

字幕草稿：
<粘贴相关行>

只输出 JSON：{"fixes":[{"n":12,"text":"改后的整行"}]}
```

agent 把各块的 fixes 合并成 `5_字幕/vN/fixes.json`，带 `--fixes` 重跑 `srt`。

## 附录：备用纯听写流程（ASR 不可用、用户同意后才用）

### 原始音频听写

**输入：** `1_音频/chunks/chunk_NNN.mp3` + `chunk_NNN.islands.txt`，可选口播稿、专名表。

```text
你在听一段口播录音（chunk_NNN，时长 X 秒）。逐字记下你听到的每一句话，给出每句在这段音频里的开始和结束秒数。
规则：
1. 逐字记录，原话照录。口误、重说、半句、重复、英文词头卡壳（如 "Cla Claude"）都要原样记下。
2. 不要参照口播稿改字，口播稿只用来确认专名写法。
3. 每条是一口气说完的一小段。独立的语气词单独成一条，kind 写 filler。
4. 咳嗽、清嗓、敲键盘等非语音声音单独成一条，kind 写 noise。
5. 时间是相对本段音频开头的秒数，两位小数，条目不重叠。
6. 按下面的有声区间编号逐个听，每条写上所在区间编号（island），一条不跨区间，不允许跳过编号：
   <粘贴 chunk_NNN.islands.txt>
7. 听出的问题写进 flags：重说 / 残句 / 卡壳 / 说错 / 听不清。
只输出 JSON：
{"chunk":"chunk_NNN.mp3","segments":[{"island":"#0001","start":0.00,"end":0.00,"text":"","kind":"speech","flags":[]}]}
```

输出 `2_听写/chunk_NNN.json`，跑 `merge`；候选按整条 `start`/`end` 写。

### 剪后字幕

```text
这是剪辑后的口播音频（chunk_NNN），要做成竖屏短视频字幕。给每行字幕的开始、结束秒数（块内时间，两位小数）和文字。
每行 ≤16 字，在停顿或意群处断行；语气词不上字幕；专名按专名表；时间贴着说话，行不重叠。
有声区间参考：<粘贴 chunk_NNN.islands.txt>
只输出 JSON：{"chunk":"chunk_NNN.mp3","lines":[{"start":0.00,"end":0.00,"text":""}]}
```

输出 `5_字幕/vN/chunk_NNN.json`，`srt --pack … --listen …`。
